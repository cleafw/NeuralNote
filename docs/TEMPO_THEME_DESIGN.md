# BPM 与主题：BMAD 轻量设计

## 需求与范围

- 作为扒谱用户，我导入歌曲后希望 BPM 自动估算，不必先生成 MIDI。
- 当自动估算不可靠、估成半拍或双倍速度时，我可以重新分析、跟拍点击或手动输入。
- 我可以在选项菜单切换亮色或暗色，重开后仍保留选择。
- 不做变速播放、节拍对齐、自动拍号或多段速度图。BPM 写入 MIDI 并用于秒到拍的换算，原音符的实际时间不变。

## 交互与组件

在波形上方复用原「导出速度」区域，显示可编辑的 BPM 数字和相邻的「测速」按钮。按钮打开小窗，提供「分析音频」「跟拍点击」「重置点击」。至少点四下才应用，停止数秒后按新一轮计数。状态显示正在分析、自动估算值或无法可靠估算；失败保留当前 BPM。BPM 在音频就绪后可用，不依赖模型。宿主录音的已知 BPM 优先，手动编辑或有效点击优先于进行中的自动结果。

在「选项 → 主题」提供「暗色」「亮色」，默认保留现有暗色。共享色板覆盖主区、波形、钢琴卷帘、控件和应用菜单；保留每种乐器的识别色和系统原生窗口外框。切换只刷新视图，不重置音频、转录结果或 BPM。

## 实现与验收

- 从已载入的单声道音频提取起音包络，在后台估算稳定节拍；分析长度有上限，不访问音频回调或模型。
- 不把静音、持续长音或不确定结果报告成 120 BPM 的测量值。首次默认值和测量值区分；新音频不会沿用上一首的结果。
- 覆盖不同速度、弱拍和八分音符、静音、点击次数和超时、手动覆盖竞态、会话 BPM 恢复和导出 tempo 事件。
- 验证两套色板、最低窗口尺寸、语言切换及 Vulkan 构建。
