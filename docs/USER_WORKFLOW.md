# 菜单、乐器混音与 MIDI 导出

## 窗口与菜单

独立程序左上角的“文件”提供打开音频、导出 MIDI、保存与载入状态；“选项”集中设备、输入静音、语言、计算设备和界面缩放等设置。默认音频输入仍保持静音，启动不再出现静音提示横幅。

软件名称和 v2 标识保留。拖动窗口改变可见内容区域，不再自动放大字体和按钮；较窄窗口的顶部控件自动分成两行。“界面缩放”单独调整控件大小，窗口尺寸与缩放分别记忆。升级时使用原来的窗口大小，控件缩放从 100% 开始。插件版本继续使用内部设置按钮，不修改宿主菜单。

独立程序右上角提供最小化、最大化/还原和关闭。菜单栏右侧的“全屏”按钮或 F11 可切换全屏，Esc 退出；全屏隐藏系统标题栏，应用内退出全屏按钮仍可用。普通窗口尺寸单独记忆，不用全屏尺寸覆盖。

## 选择与试听

侧栏第一项“原声”对应导入的原始音频，其后是乐器音轨。每行左侧的播放指示按钮控制该轨是否启用；M 为静音，S 为独奏。原声和乐器可以一起播放，也可以只启用任意组合。独奏规则覆盖所有音轨：原声独奏时只听原声，乐器独奏时关闭原声，多个 S 可一起启用。原声也有音量、声相和电平表，设置随会话保存；原声不参与 MIDI 轨道选择与导出。

旧顶部“原声/MIDI”交叉比例滑块已移除，避免其端点让已启用的音轨仍无声。旧会话仍能载入，播放由侧栏开关和各轨音量决定。

- 单击乐器行：单选；Ctrl 点击：增加或取消选择；Shift 点击：从上次点击的行连续选择；Ctrl+A：全选。
- 高亮背景表示导出选择范围，行左侧的亮色标记表示当前试听乐器。最后点击的乐器负责试听，多选不会同时叠加多个音色。
- 左键按住左侧琴键试听当前乐器，拖过琴键切换音高，松开或拖出琴键区域时释放；鼓组键位对应不同打击乐。
- 乐器音量与新增的声相旋钮影响播放和琴键试听。声相居中为默认，双击复位；向左/右旋转分别偏向左/右声道。静音和独奏继续控制播放，明确点击琴键的试听仍可发声。
- 选择结果轨道不会改变“下一次转录哪些乐器”的配置。音符、音高与时长不会因为混音操作改变。

## 导出

右键乐器行可导出当前乐器、所选乐器合并 MIDI，或把所选乐器分别导出。右键已选中的行保留多选范围；右键未选中的行先选中该行。

“文件”菜单还能导出全部乐器。合并 MIDI 中每个乐器占独立轨道；分别导出时每个乐器生成一个文件，名称包括原音频名、乐器名及乐器编号。没有音符的乐器不导出。

导出先选择是否“包含音量与声相”，默认不包含；随后选择文件或文件夹。包含时写入 CC7（音量）和 CC10（声相），不改变音符力度。MIDI CC7 范围有限，超过 MIDI 最大音量的增益会被限制在最大值。超过 15 个旋律乐器的合并导出会提示，并使用选项中现有的通道不足规则；鼓组保留第 10 通道。

批量导出遇到重名文件时统一选择覆盖、跳过或取消。导出包含哪些乐器由选择范围决定，静音/独奏不会自动过滤文件内容。原有拖拽 MIDI 操作仍默认导出全部乐器。

## 验证与更新

Windows 配置统一保存在用户主目录的 `.neuralnote` 文件夹，例如 `C:\Users\用户名\.neuralnote`。程序自动迁移旧 Roaming 配置及 Codex MSIX 缓存中的已有模型路径、设置和会话，已有规范配置优先，不搬动模型文件。这样从桌面和 Codex 启动时读取同一份配置。日志位于该文件夹的 `logs/NeuralNote.log`，启动日志记录实际配置及模型文件路径。

GPU 编译：`./Tools/build-windows-gpu.ps1 -InteractionTests`。测试覆盖选择、声相输出、试听、会话保存、MIDI 重新读取和布局几何。测试不启动独立软件主窗口。

更新后从原桌面快捷方式打开新版。更新期间如果旧窗口仍在使用，请先导出或保存结果再关闭；不要强制终止用户工作。

本次交付验证（2026-10-31）：Vulkan Release 编译成功，43 项交互、音频、会话、MIDI 和布局检查全部通过；243 条翻译词典覆盖检查及中英切换测试通过。按用户要求没有启动独立软件，尚未进行菜单、文件选择对话框及不同显示器下的人工视觉验收。构建与测试输出保存在 `build/final-validation.log`。
